# MineSpray 🚛💧

### سیستم هوشمند کنترل گردوغبار جاده‌های حمل‌ونقل معدن

MineSpray یک نمونه اولیه اپلیکیشن اندرویدی برای مدیریت هوشمند گردوغبار و مصرف آب در جاده‌های حمل‌ونقل معادن است.

ایده اصلی پروژه ساده است:

**اطلاعات محیطی → تصمیم‌گیری هوشمند → فرمان آب‌پاشی**

به‌جای اینکه کامیون‌های آب‌پاش در تمام مسیر تقریباً به یک اندازه آب پاشی کنند، MineSpray تلاش می‌کند بر اساس شرایط هر بخش از جاده مشخص کند:

**چه زمانی، کجا و چه مقدار آب باید پاشیده شود.**

---

## 🎯 هدف پروژه

یکی از روش‌های کنترل گردوغبار در معادن، استفاده از کامیون‌های آب‌پاش برای مرطوب کردن جاده‌های حمل‌ونقل است.

در یک سیستم ساده ممکن است بدون توجه به شرایط واقعی هر بخش، مقدار تقریباً یکسانی آب پاشیده شود. این موضوع می‌تواند باعث شود:

- بعضی قسمت‌ها همچنان خشک و پرگردوغبار باقی بمانند
- بعضی قسمت‌ها بیش از حد خیس شوند
- مقدار زیادی آب هدر برود
- عملکرد کامیون‌های آب‌پاش بهینه نباشد

MineSpray با هدف هوشمندتر و هدفمندتر کردن این فرآیند طراحی شده است.

---

## 🧠 ایده تصمیم‌گیری هوشمند

سیستم می‌تواند اطلاعات مختلفی را بررسی کند، از جمله:

- 🌡️ دما
- 💧 رطوبت سطح جاده
- 💨 رطوبت هوا
- 🌫️ میزان گردوغبار
- 🌬️ سرعت باد
- 🚛 میزان تردد
- 📍 موقعیت کامیون آب‌پاش
- ⏱️ زمان آخرین آب‌پاشی

سپس بر اساس این اطلاعات، وضعیت هر بخش از جاده را بررسی کرده و یک اقدام مناسب پیشنهاد می‌دهد.

برای مثال:

```text
جاده خشک + گردوغبار زیاد
          ↓
      آب‌پاشی
          ↓
     شدت بیشتر
```

```text
جاده نیمه‌مرطوب
          ↓
     آب‌پاشی محدود
          ↓
     شدت کمتر
```

```text
رطوبت کافی
          ↓
     عدم آب‌پاشی
```

نسخه اولیه سیستم می‌تواند با استفاده از قوانین تصمیم‌گیری کار کند و در مراحل بعد امکان استفاده از مدل‌های یادگیری ماشین و الگوریتم‌های بهینه‌سازی وجود دارد.
